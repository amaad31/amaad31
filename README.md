My degree says Mechatronics. In practice it's almost all software, and what holds my attention is how systems get set up, kept running, and debugged when they misbehave.

The Mechatronics half still pulls its weight: robotics, machine learning, embedded systems. A useful reminder that at some point the code has to move something real.

Master's at FAU Erlangen-Nürnberg, and Python tooling at Siemens Mobility as a working student.

### Built and building

| | |
| --- | --- |
| **AI Cloud Operations Dashboard** | Fullstack platform to monitor, debug and manage AI cloud workloads at scale |
| **Edge Kubernetes provisioning** | Racks a bare machine and hands back a cluster node, no one touching a keyboard |
| **Synclip** | File sync with encryption, over a TCP and RPC layer I wrote myself in Java |
| **LVGL embedded GUI** | A touch interface that fits in the memory a microcontroller can spare |
| **amaadakhan.dev** | My site. Next.js, own domain, deploys itself |
